Rainstone uses the canonical dark/primary/gold palette, light content surface,
Atkinson Hyperlegible typography, restrained card treatment, visible focus,
textual cost-quality labels, and reduced-motion support. IWC's compact table and
control patterns take precedence where the Hub and IWC differ.
